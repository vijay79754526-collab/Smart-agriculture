# EcoCrop reference data

`EcoCrop_DB.csv` is the OpenCLIM EcoCrop database. It contains crop ecological
requirements including temperature, rainfall, soil pH, soil texture, and
growing-duration ranges.

- Source repository: <https://github.com/OpenCLIM/ecocrop>
- Dataset DOI: <https://doi.org/10.5281/zenodo.10843625>
- License: Open Government Licence v3.0 (OGL-UK-3.0)

The recommendation service uses the source ranges as suitability evidence. The
dataset does not contain crop-specific NPK thresholds, regional planting
calendars, expected yields, or water-demand estimates; these are not inferred
or fabricated by the application.
